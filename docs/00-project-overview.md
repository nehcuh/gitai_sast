# 项目概述

> **项目名称**: VSCode SAST AI 插件  
> **版本**: v1.0  
> **更新时间**: 2025-01-29

---

## 项目目标

开发一个集成了 AI 能力的静态代码分析 VSCode 插件，提供实时代码安全扫描、智能修复建议、团队协作等功能，支持本地和远程双模式扫描。

---

## 核心能力

### 1. 智能扫描
- **本地扫描**: 基于 Opengrep 的高性能本地扫描
- **远程扫描**: 集成专业 SAST 平台的深度分析
- **增量扫描**: 只扫描变更文件，提升性能
- **多语言支持**: JavaScript/TypeScript/Python/Java/Rust 等

### 2. AI 修复
- **智能建议**: 基于 AI 的修复代码生成
- **上下文感知**: 注入污点路径、CFG、依赖等上下文
- **结果验证**: 验证修复方案的有效性

### 3. 自动化工作流
- **实时守护**: 打字时实时显示问题提示
- **保存扫描**: 保存时自动扫描当前文件
- **提交阻断**: Git 提交前自动扫描，阻断安全问题的提交
- **后台扫描**: 空闲时批量扫描整个工作区

### 4. 团队协作
- **报告导出**: 导出 Word/PDF/JSON 格式报告
- **忽略同步**: 忽略列表在团队间同步
- **问题分配**: 分配问题给团队成员并追踪
- **配置共享**: 团队配置通过 Git 同步

---

## 设计原则

### 1. 性能优先
- 多级缓存（内存、磁盘、远程）
- 增量扫描（只扫描变更文件）
- 并发控制（限制扫描并发数）
- 懒加载（按需加载规则和组件）

### 2. 用户体验
- 友好的配置向导（零门槛上手）
- 实时反馈（扫描进度、轮询状态）
- 清晰的错误提示（分类、建议、可操作）
- 国际化支持（多语言切换）

### 3. 可扩展性
- MCP 协议支持（跨 IDE 集成）
- 插件系统（第三方插件开发）
- 多 IDE 支持（VSCode、Cursor、JetBrains）
- 规则可配置（自定义规则）

### 4. 安全性
- 工作区信任检查（防止意外上传）
- 上传内容预览（敏感文件提示）
- 凭证安全存储（VSCode SecretStorage）
- 数据脱敏（日志、错误报告）

---

## 技术栈

### 后端 (MCP Server)
- **语言**: Rust
- **扫描引擎**: Opengrep CLI
- **远程通信**: HTTP/JSON + MD5 签名
- **协议**: Model Context Protocol (MCP)

### 前端 (VSCode Extension)
- **语言**: TypeScript
- **框架**: VSCode Extension API
- **UI**: Webview (面板) + Diagnostics
- **AI 集成**: VSCode LanguageModel API

### 集成
- **Semgrep Extension**: 复用其 LSP Client
- **Remote SAST Platform**: RESTful API
- **GitHub/GitLab**: 问题分配追踪
